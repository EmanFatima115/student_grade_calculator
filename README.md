Student Marks & Grade Calculator:

This is a simple Python program that takes a student's name and marks in English, Python, and Maths. It calculates the total marks and average marks, then assigns a grade and displays whether the student has passed or failed.

Features
Takes student's name as input
Takes marks for 3 subjects
Calculates total marks
Calculates average marks
Assigns a grade based on average
Displays Pass/Fail status
Grade System
Average Marks	Grade
90 or above  	A
80–89       	B
70–79       	C
Below 70    	D
Passing Criteria:
Average ≥ 50: Passed
Average < 50: Failed
