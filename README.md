# Student Marks & Grade Calculator

This is a simple Python program that calculates total marks, average marks, grade, and pass/fail status.

## Features

- Takes student's name
- Takes marks in 3 subjects
- Calculates total marks
- Calculates average marks
- Assigns grade
- Shows Pass/Fail status

## Technologies Used

- Python 3

## How to Run

1. Install Python.
2. Open the project in VS Code or PyCharm.
3. Run the Python file.
